Installer OpenClaw

OpenClaw est un agent autonome qui s'ajoute à Clipia. Il exige Node.js 24.22 ou plus récent : c'est la cause la plus fréquente d'une installation qui se termine par une erreur.

1. Vérifier Node.js (PowerShell)

node -v

Si le numéro est inférieur à v24.22, installe la version actuelle depuis nodejs.org, puis rouvre PowerShell.

2. Installer

npm install -g openclaw@latest
openclaw onboard

3. Démarrer

openclaw gateway

Il écoute sur 127.0.0.1:18789. Copie son jeton d'accès dans Clipia (Configuration → OpenClaw) ou dans la variable OPENCLAW_GATEWAY_TOKEN.

Documentation officielle : docs.openclaw.ai
