Installer en 3 minutes

Windows — installeur ou image .iso

  1. Télécharge Clipia-Setup-6.0.4-windows-x64.exe (ou l'image .iso : double-clic pour l'ouvrir, puis lance le Setup).
  2. Si Windows dit « protégé votre PC » : Informations complémentaires → Exécuter quand même.
  3. Suivant → Installer → Terminer : l'assistant plein écran s'ouvre tout seul.

Windows — portable (clé USB)

  1. Télécharge le zip portable.
  2. Clic droit → Extraire tout dans un dossier (pas depuis WinRAR).
  3. Double-clique Clipia.exe. En cas de souci : Diagnostic-Clipia.bat.

macOS

  1. Télécharge le zip macOS et dézippe-le.
  2. Glisse Clipia.app dans Applications.
  3. Premier lancement : clic droit → Ouvrir.

Linux (Debian, Ubuntu, Mint)

  1. Télécharge le .deb.
  2. sudo apt install ./clipia_6.0.4_amd64.deb
  3. Lance clipia.
