Ce que fait Clipia

Comme un assistant vocal : appelle-la

Active le mode appel 📣 : dis « Clipia », elle répond « Oui ? », écoute ta demande, puis retourne en veille. Tu peux aussi tout dire d'un trait : « Clipia, fais-moi un clip. »

« Clipia ! »
Oui ? Je t'écoute.
« Prépare une pochette d'album bleu et violet. »
C'est parti : je lance la génération et je range le résultat dans ton projet.

Le mode appel utilise la reconnaissance vocale intégrée à Chrome ou Edge : la transcription passe par le service du navigateur, ce n'est donc pas un mode 100 % hors ligne. Le micro n'est jamais actif sans que tu aies cliqué sur 📣, et tu peux le couper à tout moment.

Clipia OS : un vrai système, sur une clé USB

Un système Linux complet (base Ubuntu 24.04) qui démarre depuis une clé USB, avec bureau, navigateur, réglages, réseau, pilotes… et Clipia intégrée.

Bureau completNavigateur webFichiersTerminalRéseau & Wi-FiSon & BluetoothPilotesRéglagesInstallation sur disque

Mémoire permanente sur la clé : conversations, projets et souvenirs restent d'un démarrage à l'autre. Le « Cerveau du système » observe la machine, apprend et te propose des améliorations expliquées, sans rien changer sans ton accord.

Honnêtement : testé en machine virtuelle (BIOS et UEFI), pas encore sur du matériel réel. PC x86-64 uniquement (pas les Mac Apple Silicon), Secure Boot à désactiver.

Tutoriels d'installation

Choisis ton système. Compte 3 minutes.

Windows — installeur

  1. Télécharge Clipia-Setup-3.0.0-windows-x64.exe.
  2. Double-clique. Si Windows affiche « protégé votre PC » : Informations complémentaires → Exécuter quand même.
  3. Suivant → Installer → Terminer (aucun droit administrateur).
  4. Lance Clipia depuis le Bureau : ton navigateur s'ouvre sur Clipia.

Android et iPhone

  1. Ouvre l'application Clipia dans le navigateur du téléphone.
  2. Android (Chrome) : appuie sur Installer dans la bannière, ou menu ⋮ → Installer l'application.
  3. iPhone (Safari) : bouton Partager → Sur l'écran d'accueil → Ajouter.
  4. Dans l'app, ouvre les réglages ⚙ et colle une clé OpenRouter (gratuite) : Clipia choisit alors toute seule un bon modèle gratuit.
  5. Elle fonctionne ensuite sans ton PC, partout, et s'ouvre même hors ligne.

Windows — portable (clé USB)

  1. Télécharge le zip Clipia-Portable-3.0.0-windows-x64.zip.
  2. Clic droit → Extraire tout, sur le Bureau ou directement sur ta clé USB.
  3. Ouvre le dossier et double-clique Clipia.exe. Rien n'est installé.
  4. Pour quitter : Quitter-Clipia.exe. Tes données restent dans le dossier donnees : copie-le pour tout emporter.

macOS

  1. Télécharge le fichier macOS et dézippe-le.
  2. Glisse Clipia.app dans Applications.
  3. Premier lancement : clic droit → Ouvrir → Ouvrir (l'app n'est pas signée par Apple).
  4. Si macOS dit « endommagé » : Terminal, puis xattr -cr /Applications/Clipia.app.

Linux (Debian, Ubuntu, Mint)

  1. Télécharge clipia_3.0.0_amd64.deb.
  2. Dans un terminal : sudo apt install ./clipia_3.0.0_amd64.deb
  3. Lance clipia ou l'icône du menu Applications.

Clipia OS (clé USB bootable)

  1. Télécharge les 4 parties dans un même dossier, puis reconstitue l'archive — Windows (invite de commandes) : copy /b Clipia-USB.iso.zip.part00 + Clipia-USB.iso.zip.part01 + Clipia-USB.iso.zip.part02 + Clipia-USB.iso.zip.part03 Clipia-USB.iso.zip ; Mac/Linux : cat Clipia-USB.iso.zip.part0* > Clipia-USB.iso.zip.
  2. Dézippe Clipia-USB.iso.zip pour obtenir Clipia-USB.iso.
  3. Écris-la sur une clé de 8 Go ou plus avec balenaEtcher (efface la clé).
  4. Redémarre, ouvre le menu de démarrage (F12, Échap, F9 ou Option) et choisis la clé. Désactive le Secure Boot si besoin.

Premier lancement : Clipia se met en route

  1. Option rapide (recommandée) : crée une clé gratuite sur console.groq.com/keys, colle-la dans l'assistant de bienvenue de Clipia et clique « Tester et activer ».
  2. Option hors ligne : installe Ollama, puis clique « Installer Qwen en local » : le meilleur modèle pour ta RAM est téléchargé.
  3. Pour Claude, OpenAI, Gemini, Suno, ElevenLabs et les autres : Coffre de clés, tes clés restent chiffrées chez toi.
  4. Dis ce que tu veux créer : Clipia te propose des solutions et te guide pas à pas.
