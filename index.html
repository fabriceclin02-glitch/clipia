Télécharger Clipia — gratuit

Version 10.0.0 · Node.js déjà inclus · aucune carte demandée.

Les logiciels ne sont pas signés par un éditeur payant : Windows (« Exécuter quand même ») et macOS (clic droit → Ouvrir) affichent un avertissement normal. Vérifie l'empreinte SHA-256 sous chaque fichier. Extrais tout le zip avant de lancer Clipia.exe.

Prête en 3 minutes

🪟 Windows — installeur

Télécharge, double-clique, « Exécuter quand même » si Windows prévient, Suivant → Installer. L'assistant s'ouvre tout seul.

🪟 Windows — portable (zip)

Clic droit → Extraire tout, puis double-clique Clipia.exe. Rien à installer, prête à l'emploi (clé USB possible).

🍎 macOS

Dézippe, glisse Clipia.app dans Applications, premier lancement par clic droit → Ouvrir.

🐧 Linux

sudo apt install ./clipia_10.0.0_amd64.deb puis lance clipia.

📱 Téléphone

Ouvre l'application web, puis « Installer l'application » (Android) ou Partager → « Sur l'écran d'accueil » (iPhone).

Questions fréquentes

Clipia est vraiment gratuite ?

Oui. Tous les téléchargements sont gratuits, sans compte. Seule l'option développeur (9,90 € par mois) est payante, et elle est facultative.

Pourquoi dire « Kodi » pour l'appeler ?

« Kodi » est le mot d'appel de Clipia : dis-le et elle t'écoute. Si tu utilises aussi le lecteur multimédia Kodi, le mot peut parfois la déclencher : tu peux alors l'appeler avec la barre d'espace.

Que fait l'option développeur ?

Elle permet à Clipia de lire et d'améliorer son propre code (toujours avec ton accord, avec sauvegarde et annulation) et d'ouvrir son serveur MCP. Tu t'abonnes via PayPal, tu reçois un code par e-mail, tu l'actives dans Clipia.

Est-ce sûr ?

Clipia demande ton accord avant les actions sensibles, ne tape jamais de mot de passe ni de numéro de carte, et garde tes données sur ton ordinateur.

Ça marche sans Internet ?

Les moteurs locaux oui ; les moteurs en ligne demandent une connexion et parfois ta propre clé.

Où est la version iPhone ?

Pas d'application dans l'App Store : utilise l'application web installable depuis Safari.
