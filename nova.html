La sécurité d'abord

Clipia Nova ne stocke aucune donnée de ses utilisateurs sur un serveur. Il n'existe donc aucun fichier central à pirater.

🔒HTTPS automatiqueLes sites s'ouvrent en version chiffrée dès que possible.
🔑Clés chiffréesVos clés IA restent sur votre appareil, protégées par le coffre-fort du système.

Installation

Version non encore signée : votre système peut afficher un avertissement la première fois.

🪟 Windows
  1. Ouvrez le fichier téléchargé.
  2. Si « Windows a protégé votre ordinateur » s'affiche : cliquez sur Informations complémentaires, puis Exécuter quand même.
  3. Suivez l'installation. Clipia Nova démarre avec son animation.
🍎 Mac
  1. Ouvrez le .dmg et glissez Clipia Nova dans Applications.
  2. La première fois : clic droit sur l'application, puis Ouvrir, puis Ouvrir à nouveau.
  3. Si macOS refuse encore : Réglages Système → Confidentialité et sécurité → Ouvrir quand même.
🐧 Linux
  1. Paquet .deb : double-cliquez dessus pour l'installer.
  2. Clic droit sur le fichier → Propriétés → cochez Autoriser l'exécution.
  3. Ou dans un terminal : chmod +x Clipia-Nova-Linux.AppImage && ./Clipia-Nova-Linux.AppImage
🤖 Android
  1. Téléchargez le fichier .apk et ouvrez-le.
  2. Autorisez l'installation depuis votre navigateur si Android le demande.
  3. Touchez Installer.
🔑 Comment obtenir une clé IA ?

Un abonnement grand public (ChatGPT Plus, Claude Pro, Gemini Advanced…) ne fournit pas de clé. Il faut créer une clé API sur la console développeur du fournisseur : l'assistant de Clipia Nova vous y emmène en un clic. Gemini, Mistral, Groq et OpenRouter proposent une offre gratuite ; Ollama fonctionne sur votre ordinateur, sans clé.
