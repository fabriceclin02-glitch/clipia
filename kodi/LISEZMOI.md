# Kodi Clipia V1

Ajout pour le **Kodi officiel** (Windows, Linux, Mac, Android). Aucun contenu ni extension pirate n'est fourni.

- `repository.clipia.zip` : dépôt Clipia (installe et met à jour l'accueil).
- `plugin.video.clipia.home.zip` : « Clipia — Accueil » seul.
- Installation : Kodi → Extensions → Installer depuis un fichier zip.
- « Clipia et réglages → Tout installer » ajoute des extensions du dépôt officiel Kodi (YouTube, Arte, Catch-up TV & More, radios, podcasts, TED, Internet Archive, NASA, SoundCloud, Mixcloud, Jellyfin) ; celles qui n'existent pas dans ton dépôt sont signalées.
- TV en direct : liste de chaînes gratuites du projet iptv-org (France), via PVR IPTV Simple (redémarre Kodi ensuite).
- Non testé dans un vrai Kodi (développé sans accès à Kodi) : signale tout problème dans les Issues GitHub.
