# Versions de Clipia

Toutes les versions restent téléchargeables : rien n'est retiré quand une nouvelle version sort.
La liste à jour (avec les sommes de contrôle SHA-256) est dans [`liens.json`](liens.json) et sur la page « Versions précédentes » du site.

| Version | Contenu principal | Fichiers |
|---|---|---|
| OS 4.0 | **Clipia OS 4** : image ISO bootable (Ubuntu 24.04, Clipia 8.2), live USB, installation sur disque, Réglages, visite guidée, sphère 3D | branche `os-images` |
| 8.4.0 | GLM-5.2 (Z.ai) : moteur et étape facultative de l'installation guidée ; vidéo « code et accès à l'ordinateur » | `telechargements/` |
| 8.3.0 | Kodi (installateur + Logithèque, piloté à la voix), films/séries/TV : Prime Video, Netflix, TF1+, M6+, France.tv, Arte, Pluto TV | `telechargements/` |
| 8.2.0 | Sauvegarder mon IA (USB / Dropbox / MEGA), accueil vitrine, moteurs de clip (Canva…), touche Espace | `telechargements/` |
| 8.0.0 | X8 « deux cerveaux », travaux en arrière-plan, OpenClaw, entreprise | `telechargements/` |

Pour revenir à une version précédente : télécharge son installeur (ou son zip portable), installe-la, puis restaure ta sauvegarde `.clipiabak` (menu « Sauvegarder mon IA »).
